_{admc-short-name} welcomes suggestions for improvement from all contributors, whether new or experienced._

You can contribute to {admc-short-name} documentation by:

* Improving existing content
* Creating new content
* (_Upcoming_) Helping with translation of the documentation

== Getting started

Everybody is welcome to suggest changes by submitting a pull request. You can
also report a bug or typo with the help of a GitHub issue to the
{docs-repo-url}[`{docs-repo-name}` repository].

To get involved with the documentation:

* Familiarize yourself with the
  {docs-repo-url}[documentation repository] and the
  https://antora.org/[static site generator].
* Antora makes use of the AsciiDoc syntax.
* Understand how to
  xref:howtos/contribution-guide/suggesting-an-improvement.adoc[suggest an
  improvement] and open a pull request.
