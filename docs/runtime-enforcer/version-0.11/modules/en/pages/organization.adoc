The {rte-name} documentation has these parts:

* xref:introduction.adoc[Introduction]: what {rte-short-name} is.
* _Installation_: the quick start and the uninstall steps.
* _Concepts & Operations_: the learn, monitor, and protect phases, the
  learning configuration, the kernel and runtime requirements, the known
  limitations, and troubleshooting.
* _Reference_: the custom resource definitions, the `kubectl` plugin, and
  the resource consumption of the components.
* _Development_: the build requirements and the development environment.
* xref:personas.adoc[For who?]: the people who use {rte-short-name}.
* xref:use-cases.adoc[Use cases]: what each persona does with it.
* Organization: this page.
* xref:glossary.adoc[Glossary]: the terms used in these pages.
* xref:disclosure.adoc[Security disclosure]: how to report a vulnerability.

Most of the content is in the _Installation_, _Concepts & Operations_, and
_Reference_ sections. The sections can overlap. The {rte-short-name} project
follows the link:https://diataxis.fr/[Diátaxis] documentation framework
where it can.
