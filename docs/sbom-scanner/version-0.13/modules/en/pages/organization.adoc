The {sboms-name} documentation has these parts:

* xref:introduction.adoc[Introduction]: what {sboms-short-name} is.
* xref:quickstart.adoc[Quick start]: install {sboms-short-name} and run a
  first scan.
* _Tutorials_: how to verify the signatures of the release, and the user
  guide, with one page per feature, from registry scans to the MCP server.
* _Explanations_: how {sboms-short-name} is built and why.
* _How-tos_: tasks for the operator, such as Helm values, uninstall, and
  troubleshooting.
* _Reference_: the cluster requirements, the custom resource definitions,
  and the OpenTelemetry signals.
* xref:personas.adoc[For who?]: the people who use {sboms-short-name}.
* xref:use-cases.adoc[Use cases]: what each persona does with it.
* Organization: this page.
* xref:glossary.adoc[Glossary]: the terms used in these pages.
* xref:disclosure.adoc[Security disclosure]: how to report a vulnerability.

Most of the content is in the _Tutorials_, _Explanations_, _How-tos_, and
_Reference_ sections. The sections can overlap. The {sboms-short-name}
project follows the link:https://diataxis.fr/[Diátaxis] documentation
framework where it can.
