= {sboms-name} Uninstall
:revdate: 2026-09-01
:page-revdate: {revdate}
:page-aliases: installation/uninstall.adoc
:description: Uninstall {sboms-name} and remove its Kubernetes resources.

Remove the resources that the `helm` chart created:

[source,bash]
----
helm uninstall --namespace sbomscanner sbomscanner
----

Then remove these Custom Resource Definitions. This action also deletes
resources of these types from the cluster:

[source,bash]
----
kubectl delete crd vexhubs.sbomscanner.kubewarden.io
kubectl delete crd scanjobs.sbomscanner.kubewarden.io
kubectl delete crd registries.sbomscanner.kubewarden.io
kubectl delete crd workloadscanconfigurations.sbomscanner.kubewarden.io
----

Finally, delete the namespace where {sboms-name} was deployed:

[source,bash]
----
kubectl delete ns sbomscanner
----

This removes the PersistentVolumeClaims of PostgreSQL and NATS.

WARNING: Whether this also destroys the data depends on the `reclaimPolicy` of
your StorageClass. A `Delete` policy deletes the PersistentVolume and the
data on it. A `Retain` policy keeps the PersistentVolume, marked as
`Released`, so you can recover the data manually. Check your StorageClass
before you delete the namespace, and take a backup first if you need to keep
past reports. See xref:howtos/helm-values.adoc#backups[Backups].
